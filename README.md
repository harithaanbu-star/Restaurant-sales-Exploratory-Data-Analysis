# 📊 Topics Practiced

## ✅ Data Handling
- Loading and merging two CSV datasets (outer join)
- Dropping irrelevant columns
- Checking dataset shape and structure
- Filtering rows by conditions
- Grouping and aggregating data

## ✅ Business Analysis
- Total Revenue calculation
- Unique customer/invoice count
- Average Order Value (AOV)
- High-value order filtering (Final Total > ₹2100)
- Date-wise revenue breakdown
- Item-wise quantity analysis across specific dates
- Invoice-level drill-down

## ✅ Visualization Techniques

### Matplotlib
- Bar Chart (Top 5 items by quantity)

### Seaborn
- Bar Plot (Item popularity)

### WordCloud
- Menu item frequency visualization
- Explored multiple interpolation modes: `bilinear`, `bicubic`, `nearest`, `gaussian`, `quadric`, `hamming`
